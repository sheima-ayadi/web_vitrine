# Web Vitrine

Ce projet est une vitrine web configurée avec Docker.

## Structure du projet

- `Dockerfile` : Configuration pour la construction de l'image Docker.
- `docker-compose.yml` : Configuration pour orchestrer les conteneurs.
- `.env` : Variables d'environnement (non incluses dans le dépôt pour des raisons de sécurité).

## Installation et Lancement

1. Assurez-vous d'avoir Docker et Docker Compose installés.
2. Créez un fichier `.env` basé sur vos besoins.
3. Lancez le projet avec :
   ```bash
   docker-compose up -d
   ```
